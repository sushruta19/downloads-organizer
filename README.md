# File Organizer

## Overview
**File Organizer** is a lightweight Python utility that automatically sorts all
files in a given folder (like Downloads or Desktop) into subfolders based on
their file types. It helps declutter directories by grouping similar files
together — documents, images, videos, music, archives, executables, code files,
and more.

---

## Features
- Automatically organizes files by category  
- Supports a wide range of common file formats  
- Creates missing folders automatically  
- Works on any folder (you can specify the location)  
- Simple and dependency-free — only requires Python 3

---

## Usage
Run the script in your terminal:

```bash
python file_organizer.py "path/to/your/folder"
```
